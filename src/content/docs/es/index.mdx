## Estrategia Zero Flicker

Nos tomamos el rendimiento en serio. La **Estrategia Critters** asegura que tu tema se aplique instantáneamente, evitando el molesto parpadeo blanco antes de que el CSS cargue.

```bash
# Instalar ahora
ng add ngx-theme-stack
```
