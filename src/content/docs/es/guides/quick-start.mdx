La forma más rápida de añadir gestión de temas a tu aplicación Angular.

## 1. Instalar

Ejecuta el siguiente comando para instalar la librería y automatizar la configuración inicial:

```bash
ng add ngx-theme-stack
```

Durante la instalación, elige el **Modo Rápido** para una configuración instantánea con los temas por defecto (`light`, `dark`, `system`).

<Aside type="tip" title="🚀 ¿Usas Bun?">
Dado que `ng add` no está soportado actualmente para entornos Bun, por favor sigue este proceso de dos pasos:

1. **Instalar:**
    <Code code="bun add ngx-theme-stack" lang="bash" />
2. **Configurar:**
    <Code code="ng generate ngx-theme-stack:ng-add" lang="bash" />

Esto asegura que Bun maneje las dependencias mientras el schematic automatiza la configuración del código (providers, index.html, tokens, etc.).
</Aside>

## 2. Define tus estilos

La instalación crea un archivo `src/themes.css`. Aquí es donde defines las variables de tus temas:

```css
/* src/themes.css */
:root {
  --primary: #6c00f9;
}

[data-theme='dark'] {
  --primary: #ff0069;
}
```

## 3. Alternar temas

Inyecta el servicio `ThemeToggleService` en cualquier parte de tu aplicación para alternar entre temas:

```typescript
import { Component, inject } from '@angular/core';
import { ThemeToggleService } from 'ngx-theme-stack';

@Component({
  selector: 'app-theme-toggle',
  template: `
    @if (themeToggle.isHydrated()) {
      <button (click)="themeToggle.toggle()">
        Tema: {{ themeToggle.resolvedTheme() }}
      </button>
    } @else {
      <!-- Skeleton loader mientras se hidrata la app -->
      <div class="skeleton-toggle"></div>
    }
  `
})
export class ThemeToggleComponent {
  protected themeToggle = inject(ThemeToggleService);
}
```

<Aside type="tip" title="Evita el Layout Shift">
Usar `isHydrated()` es fundamental para una buena experiencia de usuario. Permite mostrar un estado visual neutro (skeleton) mientras Angular se hidrata, evitando que los elementos de la interfaz "salten" o cambien bruscamente cuando el estado del tema se sincroniza en el cliente.
</Aside>

<Aside type="note" title="Más utilidades">
Para casos de uso más avanzados como menús desplegables o rotación de múltiples temas, consulta `ThemeSelectService`, `ThemeCycleService` o la implementación `Custom`.
</Aside>
