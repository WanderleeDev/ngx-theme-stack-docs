Un gestor de temas potente y sencillo para **Angular 20+**. Diseñado para rendimiento y soporte SSR.

## Instalación

Para instalar la librería y configurarla automáticamente en tu proyecto, ejecuta:

```bash
ng add ngx-theme-stack
```

### Modos de Instalación

<Aside type="tip" title="🚀 ¿Usas Bun?">
Dado que `ng add` no está soportado actualmente para entornos Bun, por favor sigue este proceso de dos pasos:

1. **Instalar:**
    <Code code="bun add ngx-theme-stack" lang="bash" />
2. **Configurar:**
    <Code code="ng generate ngx-theme-stack:ng-add" lang="bash" />

Esto asegura que Bun maneje las dependencias mientras el schematic automatiza la configuración del código (providers, index.html, tokens, etc.).
</Aside>

Al ejecutar `ng add`, se te presentarán dos opciones de configuración:

<Tabs>
  <TabItem label="Modo Rápido">
    - Aplica la configuración por defecto al instante.
    - Tema inicial: `system`.
    - Modo de aplicación: `class` (añade la clase del tema al elemento `<html>`).
    - Temas disponibles: `['light', 'dark', 'system']`.
    - **Estrategia**: `critters` (Cero parpadeo mediante CSS inlining).
  </TabItem>
  <TabItem label="Modo Personalizado">
    - Elige qué temas incluir (por ejemplo, si tienes un tema `blue` o `high-contrast`).
    - Configura el tema por defecto al iniciar la aplicación.
    - Cambia la clave de `localStorage` donde se guarda la elección del tema.
    - Decide cómo aplicar los temas: mediante clases (`class`), atributos (`data-theme`), o ambos.
    - **Elige tu estrategia**: `critters` para apps modernas con SSR/SSG o `blocking` para SPAs convencionales.
  </TabItem>
</Tabs>

## ¿Qué hace `ng add` por ti?

Para ofrecer una experiencia "Zero Config", el comando de instalación automatiza lo siguiente:

<FileTree>
- .agents/
  - skills/
    - ngx-theme-stack/
      - SKILL.md (Habilidad de agente de IA opcional)
- public/
- src/
  - app/
    - app.config.ts (Configura los providers aquí)
    - app.routes.ts
    - app.ts
    - app.html
    - app.css
  - index.html (Inyecta script anti-parpadeo)
  - main.ts
  - styles.css
  - themes.css (¡Nuevo! Archivo base con variables CSS)
- angular.json (Configura estilos y optimización)
- package.json (Añade scripts "ngx-theme-stack:sync", "prestart" y "prebuild")
- tsconfig.json
</FileTree>

## Seguridad y Confianza

<div style="display: flex; gap: 10px; flex-wrap: wrap; margin-bottom: 1.5rem;">
  <a href="https://socket.dev/npm/package/ngx-theme-stack/overview/3.8.4" target="_blank" rel="noopener noreferrer">
    <img src="https://socket.dev/api/badge/npm/package/ngx-theme-stack" alt="Socket Badge" />
  </a>
</div>

La seguridad es un principio fundamental en el diseño de <Badge text="ngx-theme-stack" class="badge-angular" />. La librería cuenta con una **calificación perfecta de 100/100 en Socket.dev** en todas las categorías principales (Seguridad de la Cadena de Suministro, Vulnerabilidad, Calidad, Mantenimiento y Licencia):

- **Seguridad de la Cadena de Suministro (Supply Chain):** Escaneo estricto de dependencias y fijación mediante overrides para evitar actualizaciones maliciosas.
- **Vulnerabilidades:** Cero vulnerabilidades conocidas tanto en entornos de desarrollo como de producción.
- **Seguridad en Tiempo de Ejecución:** El script de bloqueo anti-parpadeo valida cualquier entrada de tema usando una expresión regular estricta (`/^[a-zA-Z][a-zA-Z0-9_-]*$/`) y comprueba que pertenezca a la lista de temas configurados antes de interactuar con el DOM, previniendo ataques de inyección.
- **Compilación de Plantillas Estáticas:** Las plantillas de los schematics se compilan directamente en assets de TypeScript para eliminar alertas de análisis de markdown en crudo y asegurar la confiabilidad en tiempo de compilación.
