The fastest way to add theme management to your Angular application.

## 1. Install

Run the following command to install the library and automate the initial configuration:

```bash
ng add ngx-theme-stack
```

During installation, choose the **Quick Mode** for instant setup with default themes (`light`, `dark`, `system`).

<Aside type="tip" title="🚀 Using Bun?">
Since `ng add` is currently not supported for Bun environments, please use this two-step process:

1. **Install:**
    <Code code="bun add ngx-theme-stack" lang="bash" />
2. **Configure:**
    <Code code="ng generate ngx-theme-stack:ng-add" lang="bash" />

This ensures Bun handles the dependency management while the schematic automates the code configuration (providers, index.html, tokens, etc.).
</Aside>

## 2. Define your styles

The installation creates a `src/themes.css` file. This is where you define your theme variables:

```css
/* src/themes.css */
:root {
  --primary: #6c00f9;
}

[data-theme='dark'] {
  --primary: #ff0069;
}
```

## 3. Toggle themes

Inject the `ThemeToggleService` anywhere in your application to switch between themes:

```typescript
import { Component, inject } from '@angular/core';
import { ThemeToggleService } from 'ngx-theme-stack';

@Component({
  selector: 'app-theme-toggle',
  template: `
    @if (themeToggle.isHydrated()) {
      <button (click)="themeToggle.toggle()">
        Theme: {{ themeToggle.resolvedTheme() }}
      </button>
    } @else {
      <!-- Skeleton loader while the app hydrates -->
      <div class="skeleton-toggle"></div>
    }
  `
})
export class ThemeToggleComponent {
  protected themeToggle = inject(ThemeToggleService);
}
```

<Aside type="tip" title="Avoid Layout Shift">
Using `isHydrated()` is essential for a great user experience. It allows you to show a neutral visual state (skeleton) while Angular hydrates, preventing UI elements from "jumping" or shifting abruptly when the theme state synchronizes on the client.
</Aside>

<Aside type="note" title="More utilities">
For more advanced use cases like dropdown menus or rotating multiple themes, check out `ThemeSelectService`, `ThemeCycleService`, or the `Custom` implementation.
</Aside>
